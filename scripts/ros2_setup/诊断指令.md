# Elfin5 实机调试 · 检查指令速查

> 机器:Elfin5(非 L)| ROS2 Foxy | 工作空间 `~/cos_ws/ros2_ws` | EtherCAT 网卡 `enp2s0`
> 当前硬件限制:**本机只有一个网口**(Realtek RTL8111,`enp2s0`),插机械臂就断网。
> 推荐先备一个 USB 千兆网卡(RTL8153 / AX88179):USB 网卡上网,`enp2s0` 专供机械臂。

## 2. 网卡与链路检查

```sh
# 链路状态:必须看到 state UP / LOWER_UP(网线已插且对端上电)
ip -o link show enp2s0

# 是否有 IP(机械臂场景下不需要 IP;有 DHCP 反而可能干扰总线)
ip -o -f inet addr show enp2s0

# 网卡流量统计(观察与从站通信时 RX/TX 是否在涨)
ip -s link show enp2s0
```

## 3. EtherCAT 总线扫描(最核心的诊断)

```sh
cd ~/cos_ws/ros2_ws && source install/setup.bash

# ① 扫描从站数量与状态(只读,安全)
sudo stdbuf -o0 -e0 ~/cos_ws/ros2_ws/install/soem_ros2/bin/slaveinfo enp2s0

# ② SOEM 自带的整机测试:自动把从站切到 OP 并收发过程数据
sudo stdbuf -o0 -e0 ~/cos_ws/ros2_ws/install/soem_ros2/bin/simple_test enp2s0

# ③ 读取从站 EEPROM/ESI 信息(排查从站版本问题)
sudo stdbuf -o0 -e0 ~/cos_ws/ros2_ws/install/soem_ros2/bin/eepromtool enp2s0

# ④ 独立启动驱动节点(不经过 ros2_control,输出更直白;硬编码用 enp2s0)
sudo stdbuf -o0 -e0 bash -c \
  "source ~/cos_ws/ros2_ws/install/setup.bash && ~/cos_ws/ros2_ws/install/elfin_ethercat_driver/lib/elfin_ethercat_driver/elfin_ethercat_driver"
```

> `stdbuf -o0 -e0` 让 stdout/stderr 不缓冲——否则进程 abort 时关键打印(如
> "SOEM found and configured N slaves")来不及刷出,会丢失线索。

### ③④ 输出对照表

| 输出 | 含义 | 排查方向 |
|------|------|----------|
| `Could not initialize ethercat driver` | 网卡打开失败 | 网卡名/权限/网卡被占用 |
| `No slaves are found on enp2s0` | 总线上无任何从站响应 | 网线没插/机械臂没上电/线序错 |
| `Could not set EC_STATE_PRE_OP` | 从站在但进不了 PRE_OP | 从站硬件异常/接触不良 |
| `Could not set EC_STATE_SAFE_OP` | 进不了 SAFE_OP | 同上,或从站版本不匹配 |
| `OPERATIONAL state not set` | 1~4 号从站某站进不了 OP | 模组报错(需断电重启清障)/从站数量不足/总线被网络流量干扰 |
| `Finished configuration successfully` | 初始化成功 | — |

`slaveinfo` 若显示某个从站为 `SAFE_OP + ERROR`:机械臂**断电重启**清障后再扫。

#### 实战案例:总线上只有 1 个从站(2026-08-14)

- 现象:`slaveinfo` 显示 `1 slaves found and configured`,唯一从站叫
  `Hans Robot`,`Activeports:1.0.0.0`(下游无级联);驱动报
  `OPERATIONAL state not set` 后崩溃。
- 原因:驱动硬编码要求 1~4 号从站全部进 OP(关节模组应在 2/3/4 号),
  而总线上只有 1 个从站 → 对不存在的从站做状态检查必然失败。
- 排查:
  1. 机械臂电源是否全开(模组可能有独立供电/开关);
  2. 底座内模组间的级联线是否松脱;
  3. 断电重启后重扫,期望 `slaves found` ≥ 3(2/3/4 号为关节模组);
  4. 模组始终不出现 → 联系供货方确认接线图/从站版本(Elfin 有两种从站版本)。

## 4. 单网口机器:插机械臂前必做(防止 DHCP/ARP 干扰总线)

> ⚠️ 仅在 USB 网卡到位、能正常上网后执行,否则会断网!

```sh
# 把 enp2s0 交给 EtherCAT 专用,NetworkManager 不再碰它
sudo nmcli device set enp2s0 managed no
# 清掉 IP(EtherCAT 走二层,不需要 IP)
sudo ip addr flush dev enp2s0

# 想恢复 NetworkManager 管理:
# sudo nmcli device set enp2s0 managed yes && sudo nmcli dev reapply enp2s0
```

## 5. 现成工具(cos_ws 已就绪，ROS2 工作区在 ros2_ws/)

```sh
# 网络排查(nmap 扫描端口/主机,链路/ARP 检查)
python3 ~/cos_ws/check_net.py --no-nmap          # 基础检查,不依赖 nmap
python3 ~/cos_ws/check_net.py --arp              # 只看 ARP
python3 ~/cos_ws/check_net.py --target <IP>      # 扫指定 IP 端口

# 实机一键启动(4 终端,严格 1→2→3→4,自动等待依赖就绪)
python3 ~/cos_ws/start_real.py                   # 默认 elfin5
python3 ~/cos_ws/start_real.py --check           # 只检查环境
python3 ~/cos_ws/start_real.py --list            # 只预览命令
python3 ~/cos_ws/start_real.py --no-wait         # 关闭依赖等待
python3 ~/cos_ws/start_real.py --wait-timeout 180

# 仿真一键启动(默认 elfin5)
python3 ~/cos_ws/start_sim.py --list
```

## 6. 手动启动顺序(等价于 start_real.py)

```sh
# 终端1:硬件驱动(EtherCAT 主站,必须最先起)
cd ~/cos_ws/ros2_ws && source ./install/setup.bash
sudo chrt 10 bash
source ~/cos_ws/ros2_ws/install/setup.bash
ros2 launch elfin5_ros2_moveit2 elfin5_moveit.launch.py

# 终端2:等终端1的 controller_manager 就绪后
cd ~/cos_ws/ros2_ws && source ./install/setup.bash
sudo -E bash -c "source ~/cos_ws/ros2_ws/install/setup.bash && ros2 launch elfin5_ros2_moveit2 elfin5_moveit_rviz.launch.py"

# 终端3:后台 API
cd ~/cos_ws/ros2_ws && source ./install/setup.bash
sudo -E bash -c "source ~/cos_ws/ros2_ws/install/setup.bash && ros2 launch elfin5_ros2_moveit2 elfin5_basic_api.launch.py"

# 终端4:Elfin Control Panel(先 Clear Fault 再 Servo On;关机前 Servo Off)
cd ~/cos_ws/ros2_ws && source ./install/setup.bash
sudo -E bash -c "source ~/cos_ws/ros2_ws/install/setup.bash && ros2 launch elfin_basic_api elfin_gui.launch.py"
```

## 7. 常用 ROS2 运行时检查

```sh
source ~/cos_ws/ros2_ws/install/setup.bash

ros2 node list                                  # 应看到 controller_manager / move_group 等
ros2 service list | grep controller_manager     # 控制管理器服务
ros2 control list_controllers                   # 已加载的控制器(elfin_arm_controller 等)
ros2 topic echo /joint_states                   # 关节状态(位置/速度)
ros2 topic echo /enable_state                   # 使能状态 true/false
ros2 topic echo /fault_state                    # 报错状态
```
